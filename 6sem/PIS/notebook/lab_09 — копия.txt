ЧАСТЬ 1 — только WSL (задание 1)
Шаг 1. Открыть WSL
В PowerShell напишите одну строку и Enter:

wsl -d docker-desktop
Дальше все команды ниже — только в WSL (где docker-desktop:...#).

Шаг 2. Установить пакеты
Вы написали no-cache ... — так нельзя. Нужна полная команда:

apk add --no-cache nginx nginx-mod-http-dav-ext apache2-utils cadaver
Слово apk add --no-cache в начале обязательно.

Шаг 3. Настроить nginx
sh /mnt/host/d/Univer/3_kurs/6sem/PIS/Lab_09/scripts/setup_nginx_wsl.sh
Дождитесь сообщения: WebDAV: http://localhost:8081/webdav/

Шаг 4. Запустить nginx (если ещё не запущен)
pkill nginx 2>/dev/null
rm -f /run/nginx/nginx.pid
mkdir -p /run/nginx
nginx
ps | grep nginx
Должны быть строки nginx: master process.

Шаг 5. Проверить cadaver
cadaver http://localhost:8081/webdav/
Ввод:

Username: webdavuser
Password: password123
Если подключилось, будет:

dav:/webdav/>
Команды внутри cadaver:

mkcol test
put /mnt/host/d/Univer/3_kurs/6sem/PIS/Lab_09/myfile.txt myfile.txt
get myfile.txt
ls
quit
Чтобы выйти из cadaver: quit

Задание 1 готово. WSL можно не закрывать.

Демонстрация управления порядком

  • Запуск по приоритету: Тесты с priority=1 выполняются первыми
  • Выборочный запуск по меткам: Только SMOKE тесты или только FAST тесты
  • Исключение по меткам: Запуск всех, кроме SLOW тестов
  • Пропущенные тесты: Тесты, отмеченные как SKIP
  • Ожидаемо падающие: Тесты, отмеченные как EXPECTED FAIL

Примеры команд для выборочного запуска:

runTestsByTags([TEST_TAGS.SMOKE])

runTestsByTags([], [TEST_TAGS.SLOW])

skipTest('Тест с русским языком', 'Функционал не готов')
